# Offensive Security Intro Walkthrough  
*A hands on exploration of attacker mindset and basic web enumeration techniques.*

---

## Introduction  
Offensive Security is about thinking like an attacker and simulating their actions to uncover weaknesses before real attackers do.  
In this TryHackMe room, I worked through a simulated banking application called FakeBank and used basic offensive techniques to identify hidden pages and exploit insecure functionality.

---

## Starting the Lab  
When the virtual desktop loaded, the browser opened FakeBank automatically.  
My first task was to explore the interface and identify the account information displayed on the page.

**Account Number:** `8881`

## Finding Hidden Pages  
To uncover hidden directories or pages, I used Dirb, a simple directory brute forcing tool.

### Steps  
- Opened the terminal  
- Ran Dirb against the target  
  ```
  dirb http://fakebank.thm
  ```
- Looked for lines starting with a plus sign, which indicate discovered pages

Dirb found two URLs. One of them was a hidden page that was not linked anywhere in the main site.

<img width="1228" height="617" alt="image" src="https://github.com/user-attachments/assets/caf2305a-f3c3-44ba-9c1c-e7455182fc64" />

### Hidden URL Found  
**Hidden Page:** `http://fakebank.thm/bank-transfer`

This page turned out to be an admin style transfer panel.

---

## Attacking the Admin Page  
With the hidden page discovered, I tested whether the application enforced proper access control.

### Steps  
1. Navigated to the hidden transfer page  
2. Entered my account number `8881`  
3. Deposited 2000 dollars  
4. Returned to the main account page to confirm the balance update

The application accepted the request without any authentication, which confirmed a serious access control flaw.

## Key Takeaways  
- Directory enumeration can reveal hidden functionality that developers never intended users to access  
- Missing access controls can lead to full compromise of financial systems  
- Even simple labs reinforce attacker mindset and practical workflow  
- This exercise demonstrates foundational skills relevant to SOC analysis, pentesting and vulnerability assessment
