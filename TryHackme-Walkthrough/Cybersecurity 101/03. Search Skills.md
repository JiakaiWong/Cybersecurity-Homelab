# Search Skills Walkthrough  
*A practical exercise in using online tools to gather intelligence for cybersecurity.*

---

## Introduction  
Search skills are essential in cybersecurity. Whether you are investigating a threat actor, researching a vulnerability, or trying to understand how a tool works, knowing **where** to search is just as important as knowing **what** to search for.

This room introduces several major platforms used by both offensive and defensive teams.

---

# Task 1: Shodan (TryScanMe)  
Shodan is often called a search engine for the Internet of Things, but it goes far beyond that. It continuously scans the internet for publicly exposed devices, servers, industrial systems and more.

Searching for something like `apache 2.4.1` will show servers running that version, grouped by country, organisation and port. This is extremely useful during vulnerability assessments.

<img width="1920" height="868" alt="image" src="https://github.com/user-attachments/assets/61620e65-2dc9-460c-bb38-36d6a5ed701a" />

Shodan also supports filters such as:

- **country**  
- **port**  
- **org**  
- **hostname**  

### Shodan Simulation  
Steps:  
1. Search `apache`  
2. Review the first entry  
3. Use the information to answer the question

# Task 3: Vulnerability Database (CVE)  
The CVE system provides unique identifiers for known vulnerabilities. Each CVE includes details such as impact, complexity and exploitability.  
High profile vulnerabilities often receive names like Heartbleed or Log4Shell.

<img width="1954" height="1247" alt="image" src="https://github.com/user-attachments/assets/0cf6fc03-6af4-42a7-86ba-db6cc669004d" />

ExploitDB and similar sites often include proof of concept scripts demonstrating the vulnerability.
