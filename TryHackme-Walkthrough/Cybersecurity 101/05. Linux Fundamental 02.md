## Task: File System Interaction Continued  

In this task, we learn commands that allow us to:

- create files and folders  
- move files and folders  
- delete files and folders  

|Command	|Full Name	|Purpose|
|----|----|-----|
| **touch** | Create file |
| **mkdir** | Create a folder |
| **cp** | Copy a file or folder |
| **mv** | Move or rename a file or folder |
| **rm** | Remove a file or folder |
| **file** | Determine the type of a file |

---

### Creating Files and Folders  
```
touch note
mkdir mydirectory
```

### Removing Files and Folders  
```
rm note
rm -R mydirectory
```

### Copying Files  
```
cp note note2
```

### Moving or Renaming Files  
```
mv note2 note3
```

### Checking File Type  
```
file note
```

---

### Questions and Answers  
- **How would you create the file named "newnote"?**  
  `touch newnote`

- **File type of "unknown1"?**  
  `ASCII text`

- **Move "myfile" to "myfolder"?**  
  `mv myfile myfolder`

- **Contents of the file?**  
  `THM{FILESYSTEM}`

### Understanding File Permissions  

Symbolic format:

```
rwxrwxrwx
```

|Section	| Applies To	| Example |
|----|----|-----|
| First 3 | Owner | rwx |
| Next 3 | Group | rwx |
| Last 3 | Others | rwx |

---

### Converting Symbolic Permissions to Numbers  

|Permission |	Value|
|-----|-----|
| Read (r) | 4 |
| Write (w) | 2 |
| Execute (x) | 1 |

Example:

```
rwxrwxrwx = 777
```

|Group	|Permissions	|Calculation|	Value |
|------|-----|-----|----|
| Owner | rwx | 4+2+1 | 7 |
| Group | rwx | 4+2+1 | 7 |
| Others | rwx | 4+2+1 | 7 |

---

### Common Permission Sets  

|Symbolic |	Numeric |	Meaning|
|-----------|-----------|----------|
| **rwxr-xr-x** | 755 | Owner full access, others read and execute |
| **rw-r--r--** | 644 | Owner read/write, others read only |
| **rwx------** | 700 | Only the owner has access |

---

### Why This Matters  
Understanding numeric permissions helps you:

- use commands like `chmod`  
- identify security risks  
- control access to sensitive files  

Example:

```
chmod 750 system_overview.txt
```

## Task: Common Directories

### Common Linux Root Directories

|Directory	|Description	| Common Contents |
|----------|-------------|-----------------|
| **/etc** | Stores system‑wide configuration files. | passwd, shadow, sudoers, sudoers.d |
| **/var** | Stores variable data used by services. | log, backups, opt, tmp |
| **/root** | Home directory of the root user. | myfile, myfolder, passwords.xlsx |
| **/tmp** | Temporary storage cleared on reboot. | todelete, trash.txt, rubbish.bin |

---

### Questions and Answers  
- **Where are logs stored?**  
  `/var/log`

- **Which directory behaves like RAM?**  
  `/tmp`

- **Home directory of the root user?**  
  `root`
