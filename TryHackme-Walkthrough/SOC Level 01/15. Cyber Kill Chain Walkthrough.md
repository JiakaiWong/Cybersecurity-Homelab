## Introduction
The Cyber Kill Chain, introduced by Lockheed Martin, helps defenders break down attacks into discrete phases. Each phase provides opportunities to detect, disrupt, or derail the adversary. 
This article follows the TryHackMe Cyber Kill Chain room and turns the lab tasks into an explanatory walkthrough you can use during incident response or for teaching.

1) Reconnaissance
(no supplied item — leave blank or add “third-party/vendor reconnaissance” if the form needs something)
Why: Recon is the information-gathering phase (target selection, vendor research, credential hunting). The Target breach began with reconnaissance of a third-party vendor — that’s why this stage often remains a free text entry.

2) Weaponization
→ powershell
Why: Weaponization is where attackers create a deliverable payload. PowerShell is commonly used to craft malicious payloads or bootstrap a downloader/loader (e.g., an embedded script in a document that, when executed, calls PowerShell to fetch and run the malware). On many static site forms this is the best place for a tool/runtime used to turn an exploit into an executable action.

3) Delivery
→ spearphishing attachment
Why: Delivery is how the payload reaches the victim. A spear-phishing attachment (malicious Office file, macro’d document, or weaponized PDF) directly maps to Delivery — it’s the vector used to place the weapon into the victim environment.

4) Exploitation
→ exploit public-facing application
Why: Exploitation is the action that takes advantage of a vulnerability to execute code or gain access. An exploit against a public-facing application (web app, VPN, RDP gateway, vendor portal) belongs here. In real breaches attackers often combine spearphishing with exploitation of web apps or exposed services.

5) Installation
→ dynamic linker hijacking
Why: Installation is about establishing persistence on the host. Dynamic linker (DLL) hijacking is a persistence/pivot technique where an attacker places a malicious DLL to be loaded by a legitimate program — that’s a classic installation/persistence method.

6) Command & Control (C2)
→ fallback channels
Why: C2 covers the channels used to control compromised hosts. “Fallback channels” are alternate communications the malware uses if primary channels are blocked — this is explicitly a C2 technique.

7) Actions on Objectives
→ data from local system
Why: The final stage is the attacker achieving their objective — data theft, encryption, lateral movement. “Data from local system” maps to exfiltration and data collection — exactly the Action on Objective for the Target breach (cardholder data extraction).

## Conclusion: 

Cyber Kill Chain can be a great tool to improve network defence. Is it perfect and can it be the only tool to rely on? No. 

The traditional Cyber Kill Chain or Lockheed Martin Cyber Kill Chain was last modified in 2011, which, if you remember, is the date of its establishment. The absence of updates and modifications creates security gaps. 

The traditional Cyber Kill Chain was designed to secure the network perimeter and protect against malware threats. But the cybersecurity threats have developed drastically nowadays, and adversaries are combining multiple TTP (tactics, techniques, and procedures) to achieve their goal. Adversaries are capable of defeating threat intelligence by modifying the file hashes and IP addresses. Security solutions companies are developing technologies like AI (Artificial Intelligence) and different algorithms to detect even slight and suspicious changes. 

Since the main focus of the framework is on malware delivery and network security, the traditional Cyber Kill Chain will not be able to identify Insider Threats. According to CISA(opens in new tab), "The Insider Threat is the potential for an insider to use their authorized access or understanding of an organization to harm that organization."

We recommend not only relying on the traditional Cyber Kill Chain model but also referring to MITRE ATT&CK(opens in new tab) as well as Unified Kill Chain(opens in new tab) to apply a more comprehensive approach to your defence methodologies.
